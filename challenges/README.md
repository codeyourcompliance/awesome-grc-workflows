# Legacy Challenge Guidance

This directory is retained from the pre-v2.1 model, where synthetic challenges were optional additions to public workflow pages.

Under v2.1, the runnable synthetic case is the primary public product. New exercises belong in [`cases/`](../cases/README.md) and must include the full case package rather than a narrative prompt alone.

Do not add new standalone challenge entries here.

Existing challenge material may be corrected, retired, or migrated through a separate reviewed change. Migration requires an independently fictional scenario, synthetic inputs, required professional deliverables, scoring rubric, reviewer guide, reference answer, metadata, and explicit authority boundaries.
