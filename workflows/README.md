# Legacy Workflows

This directory contains public entries created under the pre-v2.1 employer-evidence-centred workflow model.

They are retained for history and independent review. They are not v2.1 runnable case packages and must not be used as the template for new contributions.

## Restrictions

Do not add new workflow entries here.

A legacy entry may be:

- corrected where it contains a material error;
- marked retired where it is no longer defensible;
- migrated through a separate reviewed case-design process;
- retained unchanged for historical lineage.

Migration does not mean copying the page into `cases/`. A v2.1 case requires an independently fictional organization, synthetic evidence package, professional deliverables, scoring rubric, reviewer guide, reference answer, metadata, and explicit authority boundary.

Private employer research, recruitment URLs, private identifiers, internal scoring, qualification notes, and transfer records must not be added to this public directory.

New public work belongs in [`cases/`](../cases/README.md).
