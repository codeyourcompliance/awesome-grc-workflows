# Workflows

This directory contains normalized workflow entries.

Each file should represent one bounded work action, not a job title, control framework, product category, or entire department.

Use `_template.md` for new entries.

## Naming

Use lowercase kebab-case based on the work action, for example:

- `privileged-access-recertification.md`
- `remediation-evidence-validation.md`
- `dr-exercise-evidence-review.md`

## Minimum content

Every workflow must state:

- observed work task;
- required output;
- human boundary;
- technical capabilities;
- automation boundary;
- public evidence;
- maturity status;
- known uncertainty.

A challenge link is optional. A workflow should remain useful even when no challenge exists.
