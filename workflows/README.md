# Workflows

This directory contains curated public workflow entries.

Each file represents one bounded work action, not a job title, control framework, product category, or entire department.

Only patterns that meet the public admission rule belong here:

- at least three independent employers request substantially similar work;
- the normalized task is stable enough to describe without inventing an internal process;
- required outputs are marked as explicit or inferred;
- the human authorization or accountability boundary is stated or marked unresolved;
- alternative explanations have been considered;
- the entry has passed review.

`Observed` and `repeated` records remain in the private research tracker. They are not published in this directory.

Use `_template.md` for new entries.

## Naming

Use lowercase kebab-case based on the work action, for example:

- `privileged-access-recertification.md`
- `remediation-evidence-validation.md`
- `dr-exercise-evidence-review.md`

## Minimum content

Every workflow must state:

- normalized work task;
- employer demand evidence and independent-employer count;
- required outputs and their explicit or inferred basis;
- human authorization and accountability boundary;
- technical capabilities;
- automation boundary;
- contextual evidence where used;
- evidence limitations and alternative explanations;
- challenge maturity.

A challenge link is optional. A workflow must remain useful without a maintainer-owned challenge or website.
